# Changelog

## 0.1.0 — first public-build candidate

- Added the complete generational starship campaign: founding, charter selection,
  provisioning, multi-generation voyages, council decisions, succession,
  Homecoming, Chronicle, Heritage, and further charters.
- Added six maintainable ship subsystems, component fitting, officers, schools,
  factions, obligations, achievements, deterministic procedural audio, and local saves.
- Added touch/click-first onboarding and controls, display/audio settings, capture-based
  UI verification, crash logging, and direct access to the local save folder.
- Corrected the duplicate engineering event identifier that prevented retail startup.

This candidate remains subject to the human approval and clean-machine gates in
`PC_FIRST_RELEASE_HUMAN_REQUIRED.md`.
