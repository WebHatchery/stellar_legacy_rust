# Stellar Legacy 0.1.0 — First Voyage

Command a colony starship whose journey outlives every captain. Build the founding
ship, accept charters measured in generations, guide council decisions, preserve—or
transform—the founding legacy, and bring home a record that shapes the next voyage.

This first Windows release candidate contains the full English-language campaign and
uses local saves only. It includes no accounts, analytics, multiplayer, cloud saves,
or online service dependency.

Known release-candidate limitation: Windows requirements, final price, support contact,
copyright notice, and storefront identifiers await owner approval. Controller support,
Steam achievements, Steam Cloud, Trading Cards, Workshop, multiplayer, and Steam Deck
compatibility are not claimed.
