# UI redesign evidence

The responsive Agenda pass is visible in the existing portrait captures:

- [Earlier portrait baseline](ui_agenda_catalogue_portrait_existing.png)
- [Current portrait layout](ui_agenda_catalogue_portrait.png)
- [Current desktop Bridge](ui_gameplay_desktop.png)
- [Current compact Bridge](ui_gameplay_portrait.png)

The comparison shows a structural change: the current view separates the
Agenda destinations into a persistent section bar, exposes active and waiting
counts near the title, groups project queue/catalogue/readiness choices, and
keeps the primary project action in a full-width touch target. The desktop
Bridge uses the same hierarchy with voyage status, attention, ship condition,
and recent developments separated into readable panels.
